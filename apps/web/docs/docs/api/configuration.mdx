## MemoryConfig

```typescript
interface MemoryConfig {
  db: VaultDb;                    // Required
  apiKey?: string;                // Default OpenAI embed + LLM
  embed?: EmbedFn;
  llm?: LLMFn;
  model?: string;
  embeddingModel?: string;
  vectorStore?: VectorStore;      // Default: FaissVectorStore
  vectorDimensions?: number;      // Default: 1536
  entityStrategies?: Partial<Record<string, ResolutionStrategy>>;
  useEntityRegistry?: boolean;
  entityRegistryAutoRegister?: boolean;
  entityKeyPattern?: RegExp | string;
  resolveEntity?: EntityResolverFn;
  entityResolutionThreshold?: number;
  entityResolutionUseLlm?: boolean;
}
```

Resolve helpers: `resolveMemoryConfig`, `resolveEmbed`, `resolveLLM`, `resolveVectorStore`.

## Resolution strategies

```typescript
type ResolutionStrategy = "recency" | "authority";
```

| Strategy | Behavior |
| --- | --- |
| `recency` | Newest claim supersedes conflicts (default) |
| `authority` | Higher `agent_authority` weight wins; else DISPUTE |

Wildcard patterns in `entityStrategies`:

```javascript
entityStrategies: {
  "user.timezone": "authority",
  "user.schedule.*": "authority",
}
```
